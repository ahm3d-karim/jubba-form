# Jubba Sign-up

Sign-up form for the LRS Directorate jubba (LUMS Religious Society). Single static page, deployed on Vercel.

- Live form: https://jubbasignup.vercel.app
- Submissions post to a Google Apps Script web app, which writes to the responses Google Sheet and saves payment proofs to the "Jubba Signup - Payment Proofs" Drive folder.

The Apps Script source lives in the Google Sheet (Extensions > Apps Script), not in this repo.
